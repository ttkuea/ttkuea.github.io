# Backend Resume Portfolio (GitHub Pages)

Starter single-page portfolio for a backend software engineer profile.

## Files

- `index.html`: page structure and placeholder content
- `styles.css`: visual theme, layout, responsive styling, and animations
- `script.js`: active nav highlighting, reveal effects, and dynamic footer year
- `assets/headshot-placeholder.svg`: replace with your professional headshot

## Customize First

1. Replace `Your Name` and role text in `index.html`.
2. Update email links (`mailto:you@example.com`).
3. Replace LinkedIn URL (`https://www.linkedin.com/in/your-handle/`).
4. Replace project/experience placeholder content with your real achievements.
5. Swap `assets/headshot-placeholder.svg` with your actual photo file path.

## Publish to GitHub Pages

1. Create repository named `<your-github-username>.github.io`.
2. Copy these files into the repository root.
3. Push to `main`.
4. In GitHub repo settings:
   - Open `Pages`
   - Set `Build and deployment` source to `Deploy from a branch`
   - Select `main` and root (`/`)

Your site will be available at:

`https://<your-github-username>.github.io`

## Local Preview

You can preview locally from the project folder:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.
